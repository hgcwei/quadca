🔌 API 文档

适用于 CI/CD 流水线、自动化测试平台、自定义工具集成。无需安装任何环境，有 curl 即可调用。

📡 接口地址
POST https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/
📦 请求格式

Content-Type: application/json 或 text/plain

JSON 格式：

{ "csv": "Browser,OS\nChrome,Win\nFirefox,Mac" }
✅ 成功响应

状态码 200 · Content-Type: text/csv

Browser,OS,Language
Chrome,macOS,Chinese
Firefox,Windows,Japanese
Safari,Linux,English
❌ 错误响应

状态码 400 / 401 / 500

{ "error": "请求内容为空" }
📐 请求示例

JSON 格式（推荐）

# 命令行
curl -X POST -H "Content-Type: application/json" \
  -d '{"csv":"Browser,OS\nChrome,Win\nFirefox,Mac"}' \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv

# Python
import requests
resp = requests.post(
  "https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/",
  json={"csv": "Browser,OS\nChrome,Win\nFirefox,Mac"}
)
open("testcases.csv","wb").write(resp.content)

纯文本 / 文件上传

# 直接传文件
curl -X POST -H "Content-Type: text/plain" \
  --data-binary @factors.csv \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv

# 带 API Key
curl -X POST -H "Content-Type: application/json" \
  -H "X-Api-Key: sk-quadca-xxx" \
  -d '{"csv":"Browser,OS\nChrome,Win"}' \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv
⚙️ CI/CD 集成

GitHub Actions

# .github/workflows/test.yml
jobs:
  generate-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: 生成测试用例
        run: |
          curl -X POST \
            -H "Content-Type: text/plain" \
            --data-binary @factors.csv \
            https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ \
            -o testcases.csv
      - name: 执行测试
        run: pytest testcases.csv

Jenkins 流水线

📋 输入格式说明

CSV 格式规范

  • 第一行：因子名称（表头）
  • 后续行：每个因子的水平值
  • 不同因子水平数可不同（留空即可）
  • 至少需要 2 个因子
