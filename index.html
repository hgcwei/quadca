📐 Examples

        

          

            
JSON (recommended)

            
# curl
curl -X POST -H "Content-Type: application/json" \
  -d '{"csv":"Browser,OS\nChrome,Win\nFirefox,Mac"}' \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv

# Python
import requests
resp = requests.post(
  "https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/",
  json={"csv": "Browser,OS\nChrome,Win\nFirefox,Mac"}
)
open("testcases.csv","wb").write(resp.content)

          

          

            
File Upload / API Key

            
# Upload file
curl -X POST -H "Content-Type: text/plain" \
  --data-binary @factors.csv \

# With API Key
curl -X POST -H "Content-Type: application/json" \
  -H "X-Api-Key: sk-quadca-xxx" \
  -d '{"csv":"Browser,OS\nChrome,Win"}' \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv

          

        

      


      

        
⚙️ CI/CD Integration

        

          

            
GitHub Actions

            
# .github/workflows/test.yml
jobs:
  generate-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Generate test cases
        run: |
          curl -X POST -H "Content-Type: text/plain" \
            --data-binary @factors.csv \
            https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv
      - name: Run tests
        run: pytest testcases.csv

          

          

            
Jenkins Pipeline

            
stage('Generate tests') {
    sh '''
        curl -X POST -H "Content-Type: application/json" \
          -d '{"csv":"$(cat factors.csv)"}' \
          https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv
    '''
}
stage('Run tests') {
    sh 'pytest testcases.csv'
}
