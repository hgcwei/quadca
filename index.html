🔌 API 文档

    
适用于 CI/CD 流水线、自动化测试平台、自定义集成


    

      
接口地址

      
POST https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/

    


    

      
请求格式

      
支持 JSON 和纯文本两种方式：

      
# JSON 格式（推荐）
curl -X POST -H "Content-Type: application/json" \
  -d '{"csv":"Browser,OS\nChrome,Win\nFirefox,Mac"}' \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv

# 纯文本格式（直接上传 CSV 文件）
curl -X POST -H "Content-Type: text/plain" \
  --data-binary @factors.csv \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv

    


    

      
付费调用（带 API Key）

      
curl -X POST -H "Content-Type: application/json" \
  -H "X-Api-Key: sk-quadca-xxxxxxxxxxxx" \
  -d '{"csv":"Browser,OS\nChrome,Win\nFirefox,Mac"}' \
  https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv

    


    

      
GitHub Actions 集成

      
# .github/workflows/test.yml
jobs:
  generate-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: 生成测试用例
        run: |
          curl -X POST -H "Content-Type: text/plain" \
            --data-binary @factors.csv \
            https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/ -o testcases.csv
      - name: 执行测试
        run: pytest testcases.csv

    


    

      
Python 调用

      
import requests

csv_text = """Browser,OS,Language
Chrome,Windows,English
Firefox,macOS,Chinese
Safari,Linux,Japanese"""

resp = requests.post(
    "https://quadca-wmmctsihdy.cn-hangzhou.fcapp.run/",
    json={"csv": csv_text}
)

if resp.status_code == 200:
    with open("testcases.csv", "wb") as f:
        f.write(resp.content)
    print(f"生成完成，共 {len(resp.text.split(chr(10)))-1} 个测试用例")
else:
    print("错误:", resp.json().get("error"))

成功返回 CSV 格式的测试用例集，失败返回 JSON 错误信息。

# 错误（400 / 500）
{"error": "请求内容为空，请传入有效的 CSV 文本"}
